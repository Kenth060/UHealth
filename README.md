# UHealth — Aplicación Android de Salud

**Aplicación móvil para la organización de medicamentos, recordatorios de citas médicas y localización de centros hospitalarios.**

## Acerca del proyecto

**UHealth** es una aplicación móvil desarrollada en Kotlin para dispositivos Android, con el propósito de ayudar a los usuarios a organizar información relacionada con el cuidado de su salud.

La aplicación permite gestionar recordatorios de medicamentos y citas médicas, consultar información sobre medicamentos y localizar hospitales cercanos mediante un mapa interactivo.

El proyecto fue desarrollado durante el tercer año de la carrera de **Ingeniería en Computación**, como parte de la asignatura de **Programación Gráfica** de la Universidad Nacional de Ingeniería (UNI).

## Funcionalidades principales

### Recordatorios de medicamentos

Permite organizar recordatorios relacionados con la toma de medicamentos, ayudando al usuario a mantener un seguimiento de sus horarios.

### Recordatorios de citas médicas

Facilita el registro y seguimiento de citas médicas para ayudar a recordar compromisos relacionados con la salud.

### Información sobre medicamentos

Incluye una sección destinada a consultar información de medicamentos.

### Localización de hospitales cercanos

Integra un mapa para facilitar la búsqueda y ubicación de centros hospitalarios cercanos al usuario.

### Gestión de usuarios

Incorpora funcionalidades de autenticación y manejo de información de usuarios mediante servicios de Firebase.
